JUPITER CONTEXT WEBSITE — DEPLOYMENT PACKAGE

This package contains a polished static launch site for Jupiter Context.

Included:
- Responsive homepage
- Refined transparent logo treatment
- Browser favicons and mobile app icons
- LinkedIn/OpenGraph social preview image
- Copyright and trademark-style brand notices
- Privacy, Terms, Contact, and 404 pages
- robots.txt, sitemap.xml, and web app manifest
- Netlify and Vercel deployment configuration
- Security-oriented response headers

IMPORTANT BEFORE PUBLIC LAUNCH
1. Verify the official LinkedIn URL in script.js and contact.html.
2. Verify that jupitercontext.com is the domain you intend to use. The sitemap currently uses that domain.
3. The legal pages are sensible launch-stage templates, not a substitute for advice from a qualified attorney.
4. Do not replace ™ with ® unless the mark is formally registered in the relevant jurisdiction.

LOCAL PREVIEW
Open index.html, or run:
  python -m http.server 8080
Then visit http://localhost:8080

DEPLOYMENT
- Netlify: drag this folder into Netlify Drop or connect its GitHub repository.
- Vercel: import the folder/repository; no build command is required.
- GitHub Pages: publish the repository root as a static site.
